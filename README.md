# Coquinaria App — Presentación

Página estática de una sola pieza (`index.html`, HTML/CSS/JS sin dependencias) con la presentación comercial de Coquinaria App: control de proveedores, costes, recetas y stock, con lectura de albaranes por IA.

## Desarrollo local

Abrí `index.html` directamente en el navegador, o serví la carpeta con cualquier servidor estático:

```bash
npx serve .
```

## Despliegue en Vercel

Proyecto 100% estático — Vercel lo detecta automáticamente, no requiere build ni configuración adicional. Basta con importar este repo desde el dashboard de Vercel.
